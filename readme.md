# inTEG Club — готовий сайт

Це статичний сайт (HTML + CSS + JavaScript). Збирати проєкт, встановлювати Node.js або Next.js не потрібно.

## Структура
- `index.html` — сторінка сайту
- `styles.css` — дизайн та адаптивна верстка
- `config.js` — посилання на оплату
- `assets/` — всі зображення

## Як запустити
1. Розпакуйте архів.
2. Відкрийте `index.html` у браузері для попереднього перегляду.
3. Завантажте **вміст папки** (не саму папку) на ваш хостинг у `public_html` або корінь сайту. На Netlify можна перетягнути розпаковану папку в Netlify Drop.
4. Переконайтесь, що `index.html`, `styles.css`, `config.js` і папка `assets` лежать на одному рівні.

## Як ввімкнути оплату
Відкрийте `config.js` та змініть:

`const PAYMENT_URL = "";`

на справжнє посилання платіжного провайдера. Поки поле порожнє, оплата навмисно недоступна.

> Сайт не містить серверної частини, бази даних або автоматичного доступу до Telegram після оплати. Для цього потрібна окрема інтеграція з платіжною системою та Telegram-ботом.
